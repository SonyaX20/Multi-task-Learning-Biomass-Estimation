## 📐 BaseUNet - 共享编码器

所有模型共享的基础编码器结构（3层优化版本）

```
Input: [B, 3, 6, 6]
    │   VV, VH, VV/VH SAR bands
    │
    ▼
┌─────────────────────────────────────────────────────┐
│  enc1: [B, 3, 6×6] → [B, 32, 6×6]                  │
│  ┌──────────────────────────────────────┐          │
│  │ Conv2d(3→32, k=3, p=1)               │          │
│  │ BatchNorm2d(32)                      │          │
│  │ ReLU                                 │          │
│  │ Dropout2d(0.1)                       │          │
│  │ Conv2d(32→32, k=3, p=1)              │          │
│  │ BatchNorm2d(32)                      │          │
│  │ ReLU                                 │          │
│  └──────────────────────────────────────┘          │
└─────────────────────────────────────────────────────┘
    │
    ├──────────────────────────────────────────┐ (skip e1)
    │                                          │

│  └──────────────────────────────────────┘  │       │

    │                                        │

│  │ ReLU                                 │ │       │

│  └──────────────────────────────────────┘ │       │
└───────────────────────────────────────────┼───────┼─┘
    │                                       │       │
    ├───────────────────────┐ (skip e3)    │       │
    │                       │               │       │
    ▼                       │               │       │

│  bottleneck: [B, 128, 1×1] → [B, 256, 1×1]│       │ │
│  ┌──────────────────────────────────────┐ │       │ │
│  │ Conv2d(128→256, k=3, p=1)            │ │       │ │
│  │ BatchNorm2d(256)                     │ │       │ │
│  │ ReLU                                 │ │       │ │
│  │ Dropout2d(0.1)                       │ │       │ │
│  │ Conv2d(256→256, k=3, p=1)            │ │       │ │
│  │ BatchNorm2d(256)                     │ │       │ │
│  │ ReLU                                 │ │       │ │
│  └──────────────────────────────────────┘ │       │ │
└───────────────────────────────────────────┼───────┼─┼─┘
    │                                       │       │ │
    ▼                                       │       │ │
  [B, 256, 1×1]                             │       │ │
  (Bottleneck features)                     │       │ │
                                           e3      e2 e1
                                          (skip connections)
```

**关键特性**：
- ✅ 3层编码器（移除冗余的enc4）
- ✅ 适应6×6小尺寸输入
- ✅ 避免过度下采样
- ✅ 每层保留有意义的空间信息
- ✅ 跳跃连接保留多尺度特征

**尺寸变化**：
```
6×6 → enc1 → 6×6 → pool → 3×3 → enc2 → 3×3 → pool → 1×1 → enc3 → 1×1 → bottleneck → 1×1
```

## 🎯 RegressionUNet - CHM预测

用于回归任务（冠层高度模型预测）

```
                         │              │              │
                         │              │              │

┌───────────────────┐    │              │

│ ConvTranspose2d   │    │              │
│ [256→128]         │    │              │
└─────┬─────────────┘    │              │
      │                  │              │
      ├──────────────────┘              │
      │   concat                        │

```

**输出**：`[B, 1, 6×6]` - 每个像素的冠层高度（米）

**损失函数**：`MaskedRMSELoss`（处理NaN值）

**评估指标**：
- RMSE（米）
- R² Score
- MAE

## 🌲 ClassificationUNet - 树种识别

用于分类任务（15个树种类别）

```
[B, 256, 1×1] ◄─── Bottleneck (from BaseUNet)
    │
    ▼
┌────────────────────────────────────────────┐
│  Global Average Pooling                    │
│  AdaptiveAvgPool2d(1, 1)                   │
│  [B, 256, 1×1] → [B, 256]                  │
└────────────────┬───────────────────────────┘
                 │
                 ▼
┌────────────────────────────────────────────┐
│  Flatten                                   │
│  [B, 256, 1, 1] → [B, 256]                 │
└────────────────┬───────────────────────────┘
                 │
                 ▼
┌────────────────────────────────────────────┐
│  FC Layer 1                                │
│  Linear(256 → 128)                         │
│  BatchNorm1d(128)                          │
│  ReLU                                      │
│  Dropout(0.1)                              │
└────────────────┬───────────────────────────┘
                 │
                 ▼
┌────────────────────────────────────────────┐
│  FC Layer 2                                │
│  Linear(128 → 64)                          │
│  BatchNorm1d(64)                           │
│  ReLU                                      │
│  Dropout(0.1)                              │
└────────────────┬───────────────────────────┘
                 │
                 ▼
┌────────────────────────────────────────────┐
│  Output Layer                              │
│  Linear(64 → num_classes)                  │
└────────────────┬───────────────────────────┘
                 │
                 ▼
         [B, num_classes]
         (Tree species logits)
```

**输出**：`[B, 15]` - 15个树种类别的logits

**损失函数**：`FocalLoss` 或 `CrossEntropyLoss`

**评估指标**：
- Accuracy
- Precision/Recall/F1-score per class
- Confusion Matrix

**设计理念**：
- ❌ **不需要解码器**：分类只需全局特征，不需要空间重建
- ✅ **使用bottleneck特征**：最抽象的语义信息
- ✅ **全连接层层叠**：从256 → 128 → 64 → num_classes
- ✅ **Dropout正则化**：防止过拟合

## 🔀 MultitaskUNet - 联合学习

同时进行CHM回归和树种分类

```
                    SHARED ENCODER (BaseUNet)
                             │
                             │
            ┌────────────────┴────────────────┐
            │                                 │
            ▼                                 ▼
  ┌─────────────────┐              ┌──────────────────┐
  │ REGRESSION      │              │ CLASSIFICATION   │
  │ BRANCH          │              │ BRANCH           │
  └─────────────────┘              └──────────────────┘
            │                                 │
            │                                 │
            ▼                                 ▼
    [e1, e2, e3, b]                   [e1, e2, e3, b]
            │                                 │
            │                                 │
            ▼                                 ▼
  ┌─────────────────┐              ┌──────────────────┐
  │ UNet Decoder    │              │ Multi-scale      │
  │ with Skip       │              │ Feature Fusion   │
  │ Connections     │              │                  │
  │                 │              │ Pool e1 → 4×4    │
  │ up1 → dec1      │              │ Pool e2 → 4×4    │
  │ up2 → dec2      │              │ Pool e3 → 4×4    │
  │ up3 → dec3      │              │ Pool b  → 2×2    │
  │                 │              │                  │
  │ + Residual      │              │ Concat all       │
  └────────┬────────┘              └────────┬─────────┘
           │                                │
           ▼                                ▼
  ┌─────────────────┐              ┌──────────────────┐
  │ Regression Head │              │ FC Classifier    │
  │ Conv(32→16)     │              │ Linear(5632→512) │
  │ BN→ReLU         │              │ BN→ReLU→Dropout  │
  │ Conv(16→1)      │              │ Linear(512→256)  │
  └────────┬────────┘              │ BN→ReLU→Dropout  │
           │                       │ Linear(256→15)   │
           │                       └────────┬─────────┘
           │                                │
           ▼                                ▼
    [B, 1, 6×6]                      [B, 15]
    (CHM)                         (Species logits)
```

### 详细的多尺度分类头

```
Encoder Outputs:
  e1: [B, 32, 6×6]
  e2: [B, 64, 3×3]
  e3: [B, 128, 1×1]
  b:  [B, 256, 1×1]
       │    │    │    │
       │    │    │    └─────┐
       │    │    └──────┐   │
       │    └───────┐   │   │
       └────────┐   │   │   │
                │   │   │   │
                ▼   ▼   ▼   ▼
    ┌──────────────────────────────────┐
    │ Adaptive Pooling to Same Size    │
    ├──────────────────────────────────┤
    │ e1 → Pool(4×4) → [B, 32, 4×4]   │
    │ e2 → Pool(4×4) → [B, 64, 4×4]   │
    │ e3 → Pool(4×4) → [B, 128, 4×4]  │
    │ b  → Pool(2×2) → [B, 256, 2×2]  │
    └──────────────────────────────────┘
                │   │   │   │
                └───┴───┴───┘
                     │
                  Flatten
                     │
                     ▼
         ┌───────────────────────┐
         │ Concatenate           │
         │ 32×16 + 64×16 +       │
         │ 128×16 + 256×4 = 5632 │
         └───────────┬───────────┘
                     │
                     ▼
         ┌───────────────────────┐
         │ FC1: 5632 → 512       │
         │ BN → ReLU → Dropout   │
         └───────────┬───────────┘
                     │
                     ▼
         ┌───────────────────────┐
         │ FC2: 512 → 256        │
         │ BN → ReLU → Dropout   │
         └───────────┬───────────┘
                     │
                     ▼
         ┌───────────────────────┐
         │ FC3: 256 → 15         │
         └───────────┬───────────┘
                     │
                     ▼
              [B, 15] logits
```

**优势**：
- ✅ **共享编码器**：减少参数，提高效率
- ✅ **多尺度分类**：利用所有层级的特征
- ✅ **互补学习**：两个任务相互促进
- ✅ **统一训练**：端到端优化

**损失函数**：
```python
total_loss = reg_weight × RMSE_loss + cls_weight × FocalLoss
```

## 📊 参数量对比

| 模型 | Encoder | Decoder/Head | Total | 相对大小 |
|------|---------|-------------|-------|---------|
| **BaseUNet (shared)** | 173K | - | 173K | - |
| **RegressionUNet** | 173K | 183K | 356K | 1× |
| **ClassificationUNet** | 173K | 41K | 214K | 0.6× |

**说明**：
- 编码器在所有模型间共享权重（可选）
- 分类头参数远少于解码器
- 多尺度分类头增加了显著参数量（但效果更好）

## 🔄 信息流对比

### Regression: 空间信息重建
```
6×6 → 6×6 → 3×3 → 1×1 → 1×1 (bottleneck)
                    ↓
                  1×1 → 3×3 → 6×6 (with skip connections)
                    ↓
                  6×6 output (pixel-wise prediction)
```

### Classification: 空间信息聚合
```
6×6 → 6×6 → 3×3 → 1×1 → 1×1 (bottleneck)
                    ↓
                Global Pool → 256D vector
                    ↓
                FC layers → logits
```

### Multitask: 两者兼顾
```
6×6 → 6×6 → 3×3 → 1×1 → 1×1 (bottleneck)
                    ↓
        ┌───────────┴───────────┐
        ↓                       ↓
    Spatial                 Global
    Decoder              Multi-scale Pool
        ↓                       ↓
    6×6 CHM              Species logits
```

## 🎯 设计原则总结

### 1. 针对6×6优化
- ❌ **避免过度池化**：只2次池化（6→3→1）
- ✅ **保留空间信息**：每层都有意义
- ✅ **移除冗余层**：从4层encoder减到3层

### 2. 任务特定设计
- **回归**：需要解码器重建空间分辨率
- **分类**：只需全局特征，无需解码器
- **多任务**：共享编码器，独立任务头

### 3. 跳跃连接策略
- **回归**：跳跃连接至关重要（恢复细节）
- **分类**：不需要跳跃连接（只要抽象特征）
- **多任务**：回归分支使用，分类分支不使用

### 4. 特征利用
- **单尺度**（原始）：只用bottleneck → 简单但信息有限
- **多尺度**（改进）：融合所有层 → 复杂但效果更好

## 🚀 使用建议

### 选择RegressionUNet当：
- 只需要CHM预测
- 数据集较小
- 需要最快推理速度

### 选择ClassificationUNet当：
- 只需要树种分类
- 参数预算有限
- 推理速度重要

### 选择MultitaskUNet当：
- 同时需要两个任务
- 有足够训练数据（40K+）
- 期望互补学习提升性能
- 可以接受更长训练时间

## 📝 代码使用示例

```python
# Regression
model = RegressionUNet(
    in_channels=3,
    out_channels=1,
    base_channels=32,
    dropout=0.1
).to(device)

# Classification
model = ClassificationUNet(
    in_channels=3,
    num_classes=15,
    base_channels=32,
    dropout=0.1
).to(device)

# Multitask
model = MultitaskUNet(
    in_channels=3,
    out_channels=1,
    num_classes=15,
    base_channels=32,
    dropout=0.1,
    use_multiscale_cls=True  # 启用多尺度分类头
).to(device)
```
