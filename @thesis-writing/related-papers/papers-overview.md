## 1. Benchmark Data
### 1.1. General
- [**Diameter, height and species of 42 million trees in three European landscapes generated from field data and airborne laser scanning data**](https://pmc.ncbi.nlm.nih.gov/articles/PMC10823913/)
    Summary: tree-level datasets (diameter/height/species) for FR/PL/SI using inventories + ALS, validated area-based workflow.
    Presents three tree-level datasets for large landscapes in France, Poland and Slovenia covering about 42 million trees with diameter, height and species attributes.
    Attributes are generated by combining forest inventory data, vegetation maps and airborne laser scanning in an area-based modelling workflow, with validation showing good agreement with independent field measurements.
### 1.2. Canopy Height
- [**Open-Canopy: Towards Very High Resolution Forest Monitoring**](https://arxiv.org/abs/2407.09392)
	Summary: 1.5 m canopy height/∆H benchmark over France, VHR imagery + LiDAR, baselines.
	Introduces Open-Canopy, the first open-access, country-scale benchmark for 1.5 m canopy height and canopy height change estimation over large areas in France, built from very-high-resolution satellite imagery and airborne LiDAR.
	Provides standardized splits and baselines (CNNs and transformers) for canopy height and change prediction to support very high resolution forest monitoring.
    
### 1.3. Biomass
- [**The overlooked contribution of trees outside forests to tree cover and woody biomass across Europe**](https://www.science.org/doi/10.1126/sciadv.adh4097)
    Summary: European-wide 10 m canopy cover, height, AGB maps from satellite + NFIs
    Produces European-wide 10 m canopy cover, tree height and above-ground biomass maps including trees outside forests by combining satellite remote sensing with national forest inventory data.
    Quantifies how much urban and agricultural trees contribute to national tree cover and woody biomass, showing that non-forest trees hold a substantial share of the European carbon stock that is currently overlooked in inventories.

## 2. Architecture Solutions
### 2.1. Classification
- [**Attention-based adaptive spectral-spatial kernel ResNet for hyperspectral image classification**](https://www.researchgate.net/publication/347962584_Attention-Based_Adaptive_Spectral-Spatial_Kernel_ResNet_for_Hyperspectral_Image_Classification)
    Summary: A2S2K-ResNet, selective 3D kernels + attention, and improved classification metrics.
    Proposes A2S2K-ResNet, a deep network that learns selective 3D spectral–spatial convolution kernels with residual blocks and attention-based feature recalibration for hyperspectral image classification.
    Using standard hyperspectral benchmarks (e.g. Indian Pines, Pavia, Salinas), it achieves higher overall and per-class accuracies than prior CNN-based methods while keeping model size relatively compact.

- [**Mapping tree species proportions from satellite imagery using spectral–spatial deep learning**](https://www.sciencedirect.com/science/article/pii/S0034425722003145)
    Summary: Sentinel‑2 + DL to predict continuous species proportions in mixed stands, improved explained variance vs RF/CNN.
    Develops a spectral–spatial deep learning approach that maps tree species proportions in mixed forest stands from Sentinel-2 multispectral imagery and auxiliary data.
    The network predicts continuous species shares per pixel or stand, improving explained variance and reducing error compared with random forests and conventional CNN classifiers across multiple test regions.

### 2.2. Canopy Height Regression
- [**Forest Height Estimation with TanDEM-X SAR and InSAR Features using Deep Learning**](https://ieeexplore.ieee.org/document/10705348/)
    Summary: TanDEM‑X features (complex coherence etc.) into deep nets, better forest height RMSE/bias vs traditional InSAR inversion.
    Uses TanDEM-X bistatic SAR data and a set of interferometric features, including complex coherence, as inputs to deep neural networks for forest height estimation.
    Shows that learning directly from complex coherence yields more accurate height predictions than using derived decorrelation measures or traditional InSAR models, improving RMSE and bias over existing approaches.
- [**A Deep Learning Framework for the Estimation of Forest Height From Bistatic TanDEM-X Data**](https://ieeexplore.ieee.org/document/10234548/)
    Summary: fully convolutional framework regressing canopy height from TanDEM‑X InSAR; better CHM accuracy vs physical models.
    Proposes a fully convolutional deep learning framework that regresses forest canopy height from TanDEM-X bistatic InSAR data using coherence and backscatter as inputs.
    Trained against reference canopy height models from airborne LiDAR, the network captures complex relationships between SAR observables and forest structure, reducing RMSE and bias relative to conventional inversion models.

### 2.3. AGB/AGBD Modelling
- [**Improving aboveground biomass density mapping of arid and semi-arid vegetation by combining GEDI LiDAR Sentinel-1/2 imagery and field data**](https://www.sciencedirect.com/science/article/pii/S2666017225000100)
    Summary: GEDI + S1/S2 + field plots, ML models; better AGBD estimates and reduced underestimation in arid zones.
    Combines GEDI LiDAR footprints, Sentinel-1 SAR, Sentinel-2 optical imagery and field plots to train machine learning models of above-ground biomass density in arid and semi-arid ecosystems.
    The fused-data models produce wall-to-wall biomass maps that substantially reduce the systematic underestimation of biomass in dry zones compared with existing products.

- [**The global forest above-ground biomass pool for 2010 estimated from high-resolution satellite observations**](https://essd.copernicus.org/articles/13/3927/2021/)
    Summary: global 1 ha SAR-based AGB map for 2010, calibrated with ~110k measurements, improved global biomass pool estimates.
    Generates a global 1 ha resolution map of above-ground forest biomass circa 2010 by fusing multiple satellite SAR backscatter datasets with an extensive database of ground and inventory measurements.
    Provides consistent estimates of the global forest biomass pool and its spatial distribution, particularly in regions with sparse forest inventory data, and compares them to existing biomass products.

- [**A Deep Learning Framework for the Estimation of Forest Height From Bistatic TanDEM-X Data**](https://ieeexplore.ieee.org/document/10234548/)
    Summary: fully convolutional framework regressing canopy height from TanDEM‑X InSAR; better CHM accuracy vs physical models.
    Proposes a fully convolutional deep learning framework that regresses forest canopy height from TanDEM-X bistatic InSAR data using coherence and backscatter as inputs.
    Trained against reference canopy height models from airborne LiDAR, the network captures complex relationships between SAR observables and forest structure, reducing RMSE and bias relative to conventional inversion models.
